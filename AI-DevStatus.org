* What gitist is

=bisos.gitist= does git *mass-cloning* for two brands --- *gitlab* and *github*
(public, and private/enterprise via auth). It is a PyCS *seed/plant* tool built
on =bisos.csSeed='s =csCmndsList=. The brand-neutral commands marry the
=python-gitlab= and =PyGithub= libraries to the PyCS framework.

Layering: PyCS-Framework (=bisos.b.cs=) -> seeded/planted (=gitist.cs=) ->
=csCmndsList= (csSeed) -> gitist commands (=gitist_csu.py=).

* Architecture: the brand-neutral adapter design

The three commands are brand-agnostic. All brand-specific code lives in a thin
adapter layer in =gitist_csu.py=. Adding a brand = implementing that layer; the
commands do not change. This was a deliberate choice (generalize, don't
duplicate).

Brand-neutral record:
- =RepoRef= dataclass: =namespacePath= (on-disk relative path), =httpUrl=,
  =sshUrl=, =private=, =ident=.

Brand-dispatched functions (dispatch on =cmndsControlInfo.brand= via =_brand()=):
- =getGitlab()= -> python-gitlab client via =Gitlab.from_config(tag, [path])=.
- =getGithub()= -> PyGithub client; =_githubCfg()= reads =(url, token)= from the
  cfg with =configparser=, honoring =[global] default= when tag is unset.
- =listRepos(namePath)= -> [RepoRef]. gitlab: =groups.get(path).projects.list(get_all=True)=.
  github: try =get_organization(name)=, except =github.GithubException= fall back to =get_user(name)=, then =.get_repos()=.
- =getRepo(repoPath)= -> RepoRef. gitlab =projects.get=, github =get_repo=.
- =authToken()= -> token for current brand (gitlab: client.private_token; github: cfg token).
- =_httpsCredPrefix(token)= -> https userinfo: gitlab =oauth2:<token>@=, github =<token>@=.
- =_gitlabProjectToRef= / =_githubRepoToRef= -> map provider object to RepoRef.

Brand-neutral helpers (operate only on RepoRef):
- =cloneUrlForRef(ref)= -> picks the clone URL per access policy (see below).
- =cloneRef(ref, baseDir)= -> skip-if-exists, else =git clone= via =subprocess.run=;
  returns ={path, dest, status}= where status in {cloned, skipped, failed}.

* The three commands (in gitist_csu.py)

All take the group/org as a positional arg; clone commands take a mandatory
=destBaseDir= CS param (registered in =commonParamsSpecify()=; plant supplies a
default via the csCmnd =pars= dict; =--destBaseDir=...= overrides on CLI).

- =gitist_reposList <group|org>= --- list repos. Prints "=id path=" per repo;
  opResults = list of ={id, path}=.
- =gitist_reposClone --destBaseDir=DIR <group|org>= --- clone every repo of the
  group/org under DIR, mirroring =namespacePath=; skip-if-exists.
- =gitist_clone --destBaseDir=DIR <owner/repo>= --- clone a single repo.

On-disk layout: each repo lands at =destBaseDir/<namespacePath>= (gitlab
=path_with_namespace=, e.g. =group/subgroup/proj=; github =full_name=, e.g.
=owner/repo=). This is collision-free and faithful to the provider hierarchy.

* Clone-URL selection (cloneUrlForRef) --- the access policy

Driven by =cmndsControlInfo=:
- =gitAccessType == Anon= -> =ref.httpUrl= (public https, no creds).
- =gitAccessType == Auth= and =gitAuthAccessMethod in (Ssh, SshOverHttps)= ->
  =ref.sshUrl=; if =gitAccessAcct= set, the host is replaced with that
  =~/.ssh/config= =Host= alias: =git@<gitAccessAcct>:<path>=. (ssh and
  sshOverHttps share this code path; sshOverHttps differs only in the user's
  ssh config --- port 443 etc.)
- =gitAccessType == Auth= and =gitAuthAccessMethod == Https= -> =ref.httpUrl=
  with token injected: =https://<credPrefix><host>/...=.

* Config files --- IMPORTANT for a fresh machine (no ~)

Two layers:
1. *Templates in the repo* (=py3/config/{gitlab,github}Hosts.cfg=) --- no
   secrets, placeholders only. Both use =[global] default = default= plus one
   =[<tag>]= section per account; the plant selects with =serverConfigTag=.
2. *Real runtime files in $HOME* (=~/gitlabHosts.cfg=, =~/githubHosts.cfg=) ---
   hold real Personal Access Tokens; NEVER committed. The plants'
   =serverConfigPath= points here (note: PLURAL "Hosts").

On the new machine you MUST recreate the runtime files (they are not in the repo):
#+begin_src bash
cp py3/config/gitlabHosts.cfg ~/gitlabHosts.cfg && chmod 600 ~/gitlabHosts.cfg
cp py3/config/githubHosts.cfg ~/githubHosts.cfg && chmod 600 ~/githubHosts.cfg
# then edit each: paste a real PAT into the [default] (or your chosen) section.
#+end_src

Keys --- gitlab (python-gitlab native): =url=, =private_token=, =api_version=
(+ =[global] ssl_verify=, =timeout=). github (our reader): =url= (omit /
=https://api.github.com= for public; =https://HOST/api/v3= for Enterprise),
=token= (empty => anonymous public access).

A gitlab PAT needs scope =read_api= (listing) and repo read for private clone.
A github PAT needs =repo= read for private; none needed for public (just raises
rate limits). For public-only testing, leave =token= empty and =gitAccessType =
Anon= in the plant.

* Environment / venv --- IMPORTANT

The =bin/*.pcs= / =*.cs= run under =python= on PATH, which is
=/bisos/venv/py3/dev-bisos3/bin/python=. That is where =bisos.gitist= is
editable-installed and where =gitlab= (python-gitlab) and =github= (PyGithub)
live. (CLAUDE.md cites =/bisos/venv/py3/bisos3= for lint/mypy --- that is NOT the
runtime interpreter.)

Dependencies: =python-gitlab= and =PyGithub=. If PyGithub is missing on the new
machine:
#+begin_src bash
/bisos/venv/py3/dev-bisos3/bin/pip install PyGithub
python -c "from github import Github, Auth; print('ok')"   # verify under runtime python
#+end_src

* Status --- what works vs. what is untested

Verified end-to-end (run for real):
- gitlab: =reposList=, =clone=, =reposClone= --- Anon (public) path. (Tester's own
  repo was made public to exercise Anon clone.)
- github: =reposList=, =clone= --- Anon path on public org =bisos-pip=.

Wired but NOT runtime-tested:
- *Auth path on either brand* (ssh, sshOverHttps, https-token). Logic is shared
  and mirrors the verified Anon path, but needs a real PAT (=~/...Hosts.cfg=) or
  ssh key + =~/.ssh/config= Host alias to exercise. *This is the natural next
  test.*
- github =reposClone= was not mass-run (it = =listRepos= [verified] + =cloneRef=
  per repo [verified via =gitist_clone=]).


* Design decisions (the "why")

- *Generalize, don't duplicate*: one set of commands + a brand adapter (RepoRef),
  rather than gitlab_*/github_* twins.
- *Idempotency = skip-if-exists* (no pull, no error) when =destBaseDir/<ns>=
  already exists.
- *Layout = mirror namespace* (=path_with_namespace= / =full_name=) under
  =destBaseDir=.
- *destBaseDir is a CS param* (overridable per-invocation, menu-visible), not a
  =CmndsControlInfo= field; the plant supplies a default via the csCmnd =pars=.
- *github account resolution = org-then-user* fallback.
- *Config*: gitlab uses python-gitlab's =from_config= (its native cfg format);
  github uses gitist's own =configparser= reader. Both honor =[global] default=.
- *Access model on cmndsControlInfo*: =gitAccessType= (Anon/Auth) x
  =gitAuthAccessMethod= (Ssh/Https/SshOverHttps) + =gitAccessAcct= (ssh Host
  alias). Set by the plant.
